# GLOSSARY — ABK Construction Supplies

Business terms found in code, config, and seed data, in their original language where the codebase itself
uses one. The app is trilingual at the UI layer (`app/Http/Middleware/LocaleMiddleware.php:20` hardcodes
`['en'=>'en','fr'=>'fr','ar'=>'ar']`); domain naming is a mix of English identifiers, French-derived business
vocabulary, and occasional Arabic labels/data.

| Term | Language | Meaning in this codebase | Evidence |
|---|---|---|---|
| **Debt** (`debts` / `Debt`) | en (code), fr concept (*dette*) | A credit sale: materials given to a client or supplier before full payment. One row per debt, with `DebtProduct` line items. Not a loan in the financial sense — a running tab. | `app/Models/Debt.php`, `database/migrations/2024_09_19_164130_create_debts_table.php` |
| **Client debt** | — | A `Debt` row where `tractor_driver_id = 1` — the sentinel row representing a walk-in customer with no associated driver/supplier account. Surfaced via `DebtController`. | `app/Repositories/Debt/EloquentDebt.php:33-40` |
| **Supplier debt** | — | A `Debt` row where `tractor_driver_id != 1` — same table, same schema, discriminated purely by that one comparison. Surfaced via `DebtWithSupplierController`. "Supplier" here is a UI label, not a distinct entity — see next entry. | `app/Repositories/Debt/EloquentDebt.php:25-32` |
| **Supplier** (*fournisseur*) | fr concept, en label | Has no dedicated model, table, or repository. In practice, a "supplier" is a `TractorDriver` row (see below) that is not the walk-in-client sentinel (`id = 1`). `SupplierController`/`SupplierRepository` exist in source as unfinished, unroutable code and should not be treated as the real implementation. | `database/seeders/SupplierSeeder.php`, `docs/audit/raw/04-catalog.md` |
| **Tractor driver** (`tractor_drivers` / `TractorDriver`) | en | Overloaded table serving three roles: (1) the literal delivery-driver entity (`type = 'delivery'`), (2) the client/supplier discriminator sentinel for Debt (row `id = 1`), (3) the de-facto Supplier entity (any non-delivery, non-sentinel row). `type` enum: `delivery` / `normal`. `status` enum: `active` / `inactive` / `blocked`. | `app/Models/TractorDriver.php`, `database/migrations/2024_09_19_094804_create_tractor_drivers_table.php` |
| **`DRIVERY`** | en (typo) | `config/constant.php:16` defines `TRACTORDRIVER_TYPE.DRIVERY => 'drivery'` — misspelled; the actual DB enum value is `'delivery'` (`database/migrations/2024_09_19_094804_create_tractor_drivers_table.php:20`). Confirmed unused anywhere in `app/` — dead constant, do not wire it up as-is. | `config/constant.php:15-17` |
| **Building materials** (*matériaux de construction*) | fr concept, en label | The `Category` entity — top level of the two-level materials catalog. Route URI is misspelled `services/building-materals` (missing the second "i") while the route *name* is spelled correctly, `services.building-materials` — the two disagree. | `routes/web.php:53`, `app/Http/Controllers/Category/CategoryController.php` |
| **Subcategory** | en | Second catalog level, belongs to a `Category`; the actual line-item source referenced by `DebtProduct.subcategory_id`. Has an `input_type` field controlling how its value is entered/displayed. | `app/Models/SubCategory.php` |
| **ريموك** (transliterated: *Rimouk*) | ar | Arabic display label that `SubCategory::getDisplayNameAttribute()` substitutes for subcategory names matching the rebar/steel-bar diameter fractions `1/4`, `2/4`, `3/4`, `4/4` — i.e. these four raw values all render as the single Arabic term ريموك in the UI. Likely a colloquial term for a rebar/reinforcement-bar size class in the local construction trade; exact translation not confirmed from code alone. | `app/Models/SubCategory.php:31-34` |
| **Fuel station** (*station-service*) | fr concept, en label | Not a location entity — despite the name, `FuelStation` is one **fuel receipt/purchase record** billed against a `Vehicle`, not a physical gas station. Fields: `liter`, `amount`, `type_fuel` (`diesel`/`gasoline`/`gas`), `status` (`unpaid`/`paid`). | `app/Models/FuelStation.php`, `database/migrations/2024_11_03_094248_create_fuel_stations_table.php` |
| **Diesl** | en (typo) | Misspelling of "Diesel" in the method name `FuelStation::getTotalLiterTypeDiesl()` — the sibling method `getTotalAmountTypeDiesel()` in the same class spells it correctly. Same underlying `type_fuel = 'diesel'` value either way. | `app/Models/FuelStation.php:69` vs `:84` |
| **License plate composite** | — | `vehicles.license_plate` is a single string column storing three logical sub-values concatenated as `"{license} - {year} - {wilaya}"`, decoded back with `explode(' - ', ...)` in Blade rather than stored as three columns. | `app/Http/Controllers/Vehicle/VehicleController.php:57,140`, `resources/views/content/Vehicle/edit.blade.php:34-42` |
| **Wilaya** (ولاية) | ar (Algerian administrative term) | Province/administrative-division identifier, embedded as the third segment of the `license_plate` composite string above. Standard Algerian vehicle-registration convention (plates encode the registering wilaya) — consistent with the app's likely Algeria-based deployment context (trilingual en/fr/ar locale support, French-derived business terms). | `resources/views/content/Vehicle/edit.blade.php:34-42` (inferred from field name only — not spelled out elsewhere in scope) |
| **Insurance vehicle** (`insurance_vehicles` / `InsuranceVehicle`) | en | One row per insurance coverage period for a `Vehicle` (`start_date`/`end_date`). A vehicle can have many, ordered by `end_date` descending to find the current/latest one. | `app/Models/InsuranceVehicle.php` |
| **`dettessofiane`** | fr + name | Default local database name in `.env.example:15` — French *dettes* ("debts") concatenated with a proper name, "Sofiane." Reflects the app's likely origin as a single-purpose debt tracker for a person/business named Sofiane before the fuel/vehicle/catalog modules were added. | `.env.example:15` |
| **Debt history** (`debt_histories` / `DebtHistory`) | en | Audit trail of payments applied to a `Debt` — one row written per `payDebt()` call, recording the amount and date paid. Not itself soft-deletable at the model level despite the table having a `deleted_at` column (see `CONVENTIONS.md`). | `app/Models/DebtHistory.php` |
| **Toastr flash** | — (UI mechanism, not a business term) | The `toastr()` helper used throughout controllers for success/error notifications — a UI/UX convention, included here only because it's referenced constantly in module docs and is easy to mistake for a domain concept. | `yoeunes/toastr` package |

## Seed-data note

`database/seeders/SupplierSeeder.php` creates two `TractorDriver` rows with `fullname` values `'supplier'`
and `'بن لادن'` (an Arabic name). This is placeholder/test seed data, not a documented business term — noted
here only because it surfaces in the seeded database and might otherwise be mistaken for a real convention.
